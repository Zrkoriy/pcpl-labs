## Задача 5. Декоратор `print_result` (print_result.py)

Декоратор вызывает функцию, печатает ее имя и результат, а потом возвращает этот результат.

- `list` выводится по одному элементу в строке;
- `dict` выводится в столбик в виде `ключ = значение`;
- всё остальное печатается как есть.

```
> python print_result.py
!!!!!!!!
test_1
1
test_2
iu5
test_3
a = 1
b = 2
test_4
1
2
```

## Задача 6. Контекстные менеджеры `cm_timer_1` и `cm_timer_2` (cm_timer.py)

Оба менеджера считают, сколько выполнялся блок кода, и печатают `time: ...`. Сделаны двумя способами:

- `cm_timer_1` — класс с методами `__enter__` и `__exit__`;
- `cm_timer_2` — функция-генератор с декоратором `@contextmanager` из `contextlib`.

```python
with cm_timer_1():
    sleep(5.5)
# time: 5.501
```

## Задача 7. Обработка вакансий (process_data.py)

Читается `data_light.json` (путь передается при запуске), потом данные проходят через цепочку `f4(f3(f2(f1(data))))`. Каждая функция обернута в `@print_result`, а вся цепочка — в `with cm_timer_1()`.

| Функция | Что делает | Чем сделано |
|---|---|---|
| `f1` | отсортированный список профессий без повторов, регистр не учитывается | `field`, `Unique(ignore_case=True)`, `sorted(key=str.lower)` |
| `f2` | оставляет только профессии, начинающиеся со слова «программист» | `filter` + `lambda` |
| `f3` | дописывает « с опытом Python» | `map` + `lambda` |
| `f4` | к каждой профессии добавляет случайную зарплату от 100 000 до 200 000 руб. | `gen_random` + `zip` |

`f1`, `f2`, `f3` написаны в одну строку, `f4` в две.
