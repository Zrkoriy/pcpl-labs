## Задание

1. Создать виртуальное окружение и установить в него хотя бы один внешний пакет через pip.
2. Написать консольную программу на Python 3, которая работает с классами.
3. Все файлы проекта, кроме `main.py`, должны лежать в пакете `lab_python_oop`, каждый класс в своем файле.
4. Абстрактный класс «Геометрическая фигура» с абстрактным методом вычисления площади.
5. Класс «Цвет фигуры» со свойством (property) для цвета.
6. Класс «Прямоугольник» наследуется от «Геометрической фигуры», конструктор принимает ширину, высоту и цвет. Внутри создается объект «Цвет фигуры».
7. Класс «Круг» по радиусу, площадь считается через `math.pi`.
8. Класс «Квадрат» наследуется от «Прямоугольника», конструктор принимает длину стороны.
9. У прямоугольника, круга и квадрата есть метод `__repr__`, который через `format` выводит параметры, цвет и площадь. Название фигуры хранится в поле класса и возвращается методом класса.
10. В `main.py` создать (N — номер варианта):
    - прямоугольник синего цвета шириной N и высотой N;
    - круг зеленого цвета радиусом N;
    - квадрат красного цвета со стороной N;
    - и вызвать какой-нибудь метод из внешнего пакета.
11. Дополнительно: проверить программу модульными тестами.

У меня вариант 1, поэтому **N = 1**.

## Классы

| Класс | Файл | Что делает |
|---|---|---|
| `Figure` | `figure.py` | абстрактный базовый класс (`ABC`), абстрактный метод `square()` |
| `FigureColor` | `color.py` | хранит цвет, доступ через `@property color` и сеттер |
| `Rectangle` | `rectangle.py` | ширина и высота, площадь `width * height` |
| `Circle` | `circle.py` | радиус, площадь `math.pi * r²` |
| `Square` | `square.py` | наследник `Rectangle`, вызывает `super().__init__(side, side, color)` |

Название фигуры хранится в поле класса `FIGURE_TYPE`, а возвращается методом класса `get_figure_type()` (`@classmethod`). Квадрат просто переопределяет `FIGURE_TYPE`, поэтому метод заново писать не нужно.

## Запуск

```bash
cd lab2
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux/macOS окружение активируется командой `source venv/bin/activate`.

Тесты:

```bash
python -m unittest -v test_figures
```
