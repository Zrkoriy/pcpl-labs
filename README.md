## Задание

Разработать программы для решения биквадратного уравнения `Ax⁴ + Bx² + C = 0`.

1. Нужно написать три консольные программы на Python:
   - с применением процедурной парадигмы (функции, оператор `def`);
   - с применением объектно-ориентированной парадигмы (классы);
   - с применением функциональной парадигмы (сопоставление с образцом, `match`).
2. Каждая программа вводит с клавиатуры коэффициенты A, B, C, вычисляет дискриминант и действительные корни уравнения.
3. Коэффициенты можно передать через параметры командной строки. Если они не заданы, то вводятся с клавиатуры.
4. Если коэффициент введен некорректно, то его нужно вводить повторно, пока не будет введено число.

## Как решается

Делается замена `t = x²`, и решается обычное квадратное уравнение `At² + Bt + C = 0`:

- если `D < 0`, корней нет;
- если `D = 0`, один корень `t`;
- если `D > 0`, два корня `t`.

Для каждого `t > 0` получаются два корня `x = ±√t`, для `t = 0` один корень `x = 0`, отрицательные `t` пропускаются. Поэтому у уравнения может быть от 0 до 4 действительных корней.

Если `A = 0`, уравнение сводится к `Bx² + C = 0`. Если и `A`, и `B` равны нулю, это уже не уравнение, и программа об этом сообщает.

### procedural.py

- `get_coef(index, prompt)` берет коэффициент из `sys.argv`, а если его там нет или он неправильный, просит ввести с клавиатуры;
- `get_roots(a, b, c)` считает корни;
- `main()` всё это вызывает и печатает результат.

### oop.py

Класс `BiquadraticEquation` хранит коэффициенты, дискриминант и список корней. Методы:

- `read_all()` читает коэффициенты;
- `solve_square()` решает квадратное уравнение относительно `t`;
- `calculate()` переходит от `t` к `x`;
- `print_roots()` выводит ответ.

### functional.py

Все ветвления сделаны через `match/case` (нужен Python 3.10+). Повторный ввод при ошибке реализован рекурсией в `ask_coef`.

## Запуск

Нужен Python 3.10 или новее (из-за `match`).

```bash
cd lab1
python procedural.py 1 -5 4
python oop.py
python functional.py 4 -4 1
```

Без параметров программа спросит коэффициенты сама.
